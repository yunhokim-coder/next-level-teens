# 카드·문항 초안 (개발자 검토용)

검토가 끝나면 `data/*.json`으로 옮기고 영어(`en`)를 붙인다.
태그는 원작과 같은 8개를 쓴다: 마음 진정(calm), 자기 응원(selfworth), 시작하기(start), 집중(focus), 계획(plan), 공부 방법(method), 동기(motivation), 관계(relation).
배틀에서 블랙맘바와 카드의 태그가 겹치면 "효과 큼"이다.

---

## 1. 종착역: 미래의 나 (3화)

직업명이 아니라 "어떤 사람이 되고 싶은지"를 고른다. 1개 고르기, 직접 쓰기(기기에만 저장), 아직 모름.

| # | 종착역 |
|---|---|
| 1 | 누군가를 돕고 지키는 사람 |
| 2 | 내가 만든 걸 세상에 보여주는 사람 |
| 3 | 궁금한 걸 끝까지 파고드는 사람 |
| 4 | 사람들을 이끌고 일을 성사시키는 사람 |
| 5 | 몸과 기술로 무언가를 해내는 사람 |
| 6 | 사람의 마음을 움직이는 말과 글을 쓰는 사람 |
| 7 | 문제를 숫자와 논리로 푸는 사람 |
| 8 | 세계를 무대로 움직이는 사람 |
| 9 | 가족과 주변 사람을 든든하게 챙기는 사람 |
| 10 | 내 일을 스스로 만들어 가는 사람 |
| 11 | 자연과 생명을 다루는 사람 |
| 12 | 한 분야에서 "그건 저 사람한테 물어봐"라는 말을 듣는 사람 |
| - | 직접 쓰기 / 아직 모름 (안개 낀 역) |

**유용성 질문 (노바):** "지금 하는 공부가 그 역에 어떻게 이어질 것 같아?" 칩 여러 개 고르기 + 직접 쓰기
- 그 일에 필요한 지식이 생긴다 / 생각하는 힘이 길러진다 / 선택지가 넓어진다 / 끝까지 해 본 경험이 생긴다 / 원하는 학교·과정에 갈 수 있다 / 나를 믿게 된다 / 아직 잘 모르겠다

## 2. 연료 게이지: 나를 움직이는 이유 (3화)

원작 열정·보상 에너지와 마음 게이지를 자기결정성 이론 순서로 다시 짠다. "나도 그래" 체크 12문항 → 가장 많이 체크된 게이지가 내 주 연료.

| 게이지 | 문항 |
|---|---|
| 흥미 (내적) | 1. 재밌으면 시간 가는 줄 모르고 한다. 2. 모르던 걸 알게 될 때 기분이 좋다. |
| 성장 (유능감) | 3. 어제보다 나아졌다는 느낌이 나를 움직인다. 4. 어려운 문제를 풀었을 때 짜릿하다. |
| 의미 (동일시) | 5. 이게 내 미래에 필요하다고 느끼면 한다. 6. 내가 정한 목표라면 싫어도 한다. |
| 연결 (관계) | 7. 누가 같이 하거나 응원해 주면 더 잘된다. 8. 믿어 주는 사람을 실망시키고 싶지 않다. |
| 인정·보상 (외적) | 9. 점수나 등수가 오르면 힘이 난다. 10. 칭찬이나 보상이 있으면 더 한다. |
| 압박 (통제) | 11. 안 하면 혼나거나 뒤처질까 봐 한다. 12. 남들이 다 하니까 나도 한다. |

압박 게이지가 가장 높게 나오면 노바가 "그 연료로도 달릴 수는 있어. 근데 오래 가려면 다른 연료도 섞어 보자"라고 말한다 (판단하지 않는 말투).

## 4. 우회 노선 카드 36장 (5화)

원작의 구름기둥(마음을 지켜 주는 카드)·불기둥(앞길을 비추는 카드)을 두 노선으로 바꾼다.
- **마음 노선** (12): 감정, 동기, 관계
- **공부 노선** (24): 학습과학 기반 공부법과 습관

## 5. 검토할 점
- 카드 수 36+36은 원작(55+55)보다 줄였다. 고르는 시간을 줄이고 청소년에게 맞는 것만 남겼다. 더 필요하면 추가한다.
- 원작 카드 중 청소년에게도 맞는 것(예: 반복 학습, 요점 말하기)은 공부 노선 카드에 흡수했다.
- 입시·진로 관련 블랙맘바(20 늦었다, 22 정답)는 고등학생에게 더 자주 보이게 할 수 있다.
