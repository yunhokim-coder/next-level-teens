# 데이터 저장과 보기 (Google 스프레드시트)

게임이 보내는 익명 데이터는 연구자의 Google 스프레드시트에 쌓이고, 연구자는 그 시트를 열어서 본다.
서버나 로그인은 없다.

## 무엇이 저장되나

| 시트 탭 | 언제 | 내용 |
|---|---|---|
| `register` | 승객 등록 직후 | 익명 코드, 학교 코드(`?s=`), 언어, 학년, 성별, 성적 수준(자기 평가), 동의 여부 |
| `pre` | 게임 시작 전 | 학업 효능감 5문항 e1~e5 (PALS, 1~5) |
| `post` | 게임 끝 | 같은 5문항 (1~5) |
| `satisfaction` | 게임 끝 | 만족도 3문항 (1~5) |
| `disc_result` | 2화 | 24개 응답, 유형별 점수, 1·2순위 |
| `avatar` | 2화 | 고른 겉모습 동물 |
| `ep3_result` | 3화 | 종착역(예시면 R1~C2와 RIASEC 유형, 직접 쓰기는 'own'만, 모름은 'unknown'), 연료 체크 번호, 게이지별 개수, 주 연료, 유용성 칩 |
| `ep4_result` | 4화 | 고른 카드 번호, 마음·생각·행동 개수, 카드별 빈도(1~3), 이름 방식(추천 번호 또는 'own'; 이름 글자는 보내지 않음) |
| `ep5_result` | 5화 | 턴마다 `맘바번호>카드번호:태그일치(1/0)`(전체 카드에서 고르면 뒤에 d), 턴 수, 일치 수, 전체 카드 사용 수, 마음·공부 노선 카드 수 |
| `ep6_result` | 6화 | 경유역 예시 사용 여부(3자리, 1=예시), 실행 의도 `맘바번호>카드번호`, 그 둘의 태그 일치 여부, 역 이름 방식(추천 번호 또는 'own'). 경유역 글과 역 이름 글자는 보내지 않음 |
| `routemap` | 카드 저장·인쇄 때 | 카드와 형식(route-square, route-wallpaper, route-print, profile-square 등), 다시 보기 여부 |
| `episode_complete` | 각 역을 지날 때 | 역 번호, 다시 보기 여부 |

익명 코드(예: `KT-4821`)로 같은 학생의 사전·사후를 잇는다.
**저장하지 않는 것:** 이름, 학번, 연락처, 사진, 학생이 직접 쓴 글(종착역 직접 쓰기, 그림자 이름, 경유역, 역 이름 등).
학생이 동의하지 않으면 아무것도 보내지 않고 게임만 진행된다.

## 연결 방법 (한 번만)

1. Google 드라이브에서 새 스프레드시트를 만든다. 이름 예: `NEXT LINE 데이터`
2. 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. 기본 코드를 지우고 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣고 저장한다.
4. **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사한다.
6. `config.js`의 `APPS_SCRIPT_URL`에 붙여 넣는다.
7. **IRB 승인과 보호자 동의 절차가 준비된 뒤에만** `config.js`의 `DATA_COLLECTION`을 `true`로 바꾼다.

## 데이터 보기

- 스프레드시트를 열면 탭별로 한 줄씩 쌓인다. 첫 열 `received`는 받은 시각.
- 사전·사후 비교: `pre`와 `post` 탭을 `code` 열로 짝지어 본다 (스프레드시트 `XLOOKUP` 또는 내보내서 R·SPSS).
- 학교 구분: 학교마다 다른 링크를 준다. 예) `…/next-level-teens/?s=A` (농촌), `?s=B` (도시)

## 윤리 메모

- 게임 안의 동의는 **학생 본인 동의(assent)** 다. 연구로 쓰려면 IRB 승인과 보호자 동의를 따로 받는다 (만 14세 미만은 법정대리인 동의 필요).
- 시트는 연구자 계정에만 공유한다.
